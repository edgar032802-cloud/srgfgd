# 인터넷에 올리기

지금은 이 컴퓨터에서만 열린다. 다른 사람 휴대폰으로도 열리는 주소를 만드는 방법.

---

## 0. 먼저 알아야 할 것

**이 사이트는 정적 페이지가 아니다.** 체험 예약 때문에 서버가 계속 돌아야 한다.
그래서 깃허브 페이지스처럼 파일만 올리는 곳에는 올릴 수 없다 — 올리면 화면은 뜨지만
예약·대기열·운영 화면이 전부 죽는다. **Node 를 돌려 주는 곳**이어야 한다.

배포에서는 프로세스가 하나다. 서버가 API 와 화면을 함께 내보낸다.

```bash
npm install
npm run build     # 화면을 dist/ 로 굽는다
npm start         # 서버가 dist/ + API 를 같은 주소로 내보낸다
```

`npm start` 로 뜬 주소 하나만 있으면 전부 동작한다. 확인은 `http://localhost:8787`.

---

## 1. 하루짜리 행사면 — 터널 (가장 빠름, 가입 없음)

이 노트북을 그대로 쓰되 바깥에서 들어올 수 있는 주소만 빌린다. **5분이면 된다.**

```bash
npm run build
npm start
```

다른 터미널에서:

```bash
cloudflared tunnel --url http://localhost:8787
```

`https://무슨무슨-단어.trycloudflare.com` 같은 주소가 뜬다. 이게 방문자가 열 주소다.
HTTPS 가 이미 붙어 있어 휴대폰에서 바로 열린다.

- `cloudflared` 설치: <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>
- **노트북을 끄거나 터미널을 닫으면 주소가 죽는다.** 행사 내내 켜 둬야 한다.
- 주소가 실행할 때마다 바뀐다. 행사 아침에 한 번 켜고, 그때 나온 주소로 QR 을 만들어 붙이면 된다.
- 학교 와이파이가 막고 있으면 휴대폰 핫스팟으로 붙이면 대개 뚫린다.

## 2. 계속 남는 주소가 필요하면 — 호스팅

노트북과 무관하게 항상 켜져 있는 주소. **Railway · Render · Fly.io** 중 아무거나.
셋 다 Node 프로젝트를 알아서 알아본다.

1. 코드를 깃허브 저장소에 올린다(**`.env` 는 올라가지 않는다** — `.gitignore` 에 있다).
2. 플랫폼에서 그 저장소를 고른다.
3. 명령을 이렇게 준다.
   - Build: `npm install && npm run build`
   - Start: `npm start`
4. 환경변수를 넣는다(플랫폼 대시보드에서). `.env` 에 있는 것과 같다.
   ```
   SOLAPI_API_KEY, SOLAPI_API_SECRET, SMS_SENDER
   BOOTH_ADMIN_PASSWORD        ← 3618 말고 다른 것으로. 3절 참고
   TOSS_SECRET_KEY             ← 결제를 쓸 때만
   BOOTH_DATA_DIR=/data        ← 5절 참고
   ```
5. `무엇무엇.up.railway.app` 같은 주소가 나온다. 끝.

포트는 건드리지 않아도 된다. 플랫폼이 `PORT` 로 알려 주고 서버가 그것을 받는다.

### 주소를 예쁘게 하려면

`.com`·`.kr` 도메인을 사서(가비아·후이즈·Cloudflare, 연 1~2만 원대) 플랫폼의 도메인 설정에 연결한다.
`freesia-shingu.com` 처럼 된다. 학생회 계정으로 사 둬야 나중에 인수인계가 된다.

## 3. 올리기 전에 반드시 — 비밀번호

**환경변수를 넣지 않으면 운영 화면이 아예 열리지 않는다.** `3618` 은 개발용 기본값이고 저장소에
적혀 있는 값이라, 배포에서는 그 값으로 넘어가지 않도록 서버가 스스로 잠근다(방문자 예약은 정상 동작).
네 자리 숫자는 만 번만 넣어 보면 뚫리고, 그 뒤에 **예약자 전원의 이름과 전화번호**가 있다.

플랫폼 환경변수에 이렇게 넣는다.

```
BOOTH_ADMIN_PASSWORD=문자와숫자를섞은긴것
```

넣지 않으면 운영 화면에서 "운영 화면이 잠겨 있습니다" 안내만 뜬다 — 비밀번호가 틀린 게 아니라 아직 안 넣은 것이다.

## 4. "검색해서 나오게" 하려면

주소를 만드는 것과 **구글에 나오는 것은 다른 일**이다.

- 구글은 스스로 돌아다니며 찾는다. 새 주소가 검색에 잡히기까지 보통 **며칠에서 몇 주**다.
  하루짜리 행사에는 맞지 않는다.
- 앞당기려면 [구글 서치 콘솔](https://search.google.com/search-console)에 주소를 등록하고
  색인을 요청한다. 그래도 당일에 되지는 않는다.
- `trycloudflare.com` 같은 임시 주소는 검색에 잡히지 않는다(그래야 맞다).

**행사에서 실제로 통하는 것은 QR 코드다.** 주소를 QR 로 만들어 부스 앞과 포스터에 붙이면,
찾아서 오는 게 아니라 서서 찍는다. 인스타그램 프로필 링크에 걸어 두는 것도 같이 하면 좋다.

## 5. 예약 기록이 날아가지 않게

예약은 `server/data/booth.json` 파일 하나에 쌓인다. 그런데 **호스팅 플랫폼의 파일 시스템은
대개 휘발성이라, 서버가 한 번 다시 뜨면 그날의 줄이 통째로 사라진다.**

- Railway·Fly 는 볼륨(디스크)을 붙일 수 있다. `/data` 에 붙이고 환경변수에
  `BOOTH_DATA_DIR=/data` 를 넣으면 다시 떠도 남는다.
- 볼륨이 없는 무료 요금제라면, 서버가 다시 뜰 때 줄이 사라진다는 것을 알고 써야 한다.
  1절의 터널 방식은 노트북 파일에 쌓이므로 이 문제가 없다.

## 6. 행사가 끝나면

- `server/data/booth.json` **삭제**(이름·전화번호가 들어 있다).
- Solapi 키 재발급(채팅으로 오간 값이다).
- 호스팅을 계속 둘 생각이 아니면 프로젝트를 내린다.
