# 디자인 레퍼런스 — 실측 기록

2026-08-23. 세 곳의 실제 computed style을 브라우저에서 추출한 값이다.
인상이 아니라 측정치이므로, 수치는 그대로 가져다 쓸 수 있다.

---

## 1. MLB 코리아 (mlb-korea.com)

한국 대형 커머스의 표준 문법. 우리 사이트의 **구조·타이포**가 참고할 곳.

| 항목 | 실측값 |
|---|---|
| 폰트 | **Pretendard 단일** (1470개 요소 전부) |
| 본문 | 16px / line-height 24px (1.5) |
| 보조 | 14px / 18px, 12px / 18px, 10px |
| 제목 | 28px, 36px — **크기 점프가 작다** |
| 굵기 | **400과 700 둘뿐** (500은 4곳) |
| 자간 | `normal` — 조정 안 함 |
| 라운드 | **24px(119) · 18px(118)** 지배적, 알약 99px, 16px |
| 배경 | `#f8f8f8` 지배, `#000` 45, `#f0f0f0`, `#e7e7e7` |
| 텍스트 | `#000` → `#787878` → `#949494` 3단 |
| 컨테이너 | max-width 1920px (풀블리드) |

**규칙으로 정리하면**

- 폰트는 하나만. 굵기는 400/700 이분법. 중간 굵기로 위계를 만들지 않는다.
- 위계는 **굵기와 색**으로 만든다. 크기 차이는 최소한만.
- 한글은 자간을 건드리지 않는다. `letter-spacing: normal`이 기본값.
- 모서리를 크게 굴린다(18~24px). 이게 한국 커머스의 "요즘 느낌"을 만든다.
- 회색 배경(`#f8f8f8`) 위에 흰 카드. 순백 배경을 쓰지 않는다.
- 텍스트 회색은 정확히 3단계만.

## 2. GOLDY (store.goldy.jp)

MLB와 **정반대**. 편집숍·스트리트 감성. 우리 사이트의 **디테일**이 참고할 곳.

| 항목 | 실측값 |
|---|---|
| 폰트 | **SF Mono 지배**(490) + Poppins(41) |
| 본문 | **12px** 지배, 11.05px, 10.4px |
| 굵기 | 400 지배, 500·700 소량 |
| 자간 | **0.65px 기본 / 3.12px 강조** |
| 라운드 | **거의 없음** — 전체에서 2곳뿐 |
| 배경 | **흰색 74** + 빨강 `#C92427` 1, `#0F0F0F` 1 |
| 텍스트 | `#000` 111 — 사실상 순흑 단일 |
| 컨테이너 | max-width 1500px |

**규칙으로 정리하면**

- 글자를 **작게**(12px) 쓰고 **자간을 넓힌다**(0.65~3.12px). 이 조합이 이 감성의 핵심이다.
- 모서리를 굴리지 않는다. 직각이 기본.
- 색을 거의 안 쓴다. 흰 바탕 + 검정 글자 + 빨강 한 점.
- 라벨·내비는 전부 대문자 + 넓은 자간.
- `PRE ORDER`처럼 굵은 디스플레이 타이포를 히어로에 크게 얹는다. — 사전판매인 우리 사이트가 바로 가져올 수 있는 패턴.

## 3. riosense (Behance 케이스)

웹사이트가 아니라 브랜드 아이덴티티 작업물. **색과 태도**가 참고할 곳.

작업물 이미지에서 추출한 팔레트:

| 색 | 역할 |
|---|---|
| `#D4C7BC` | 지배색 — 따뜻한 모래/그레이지 |
| `#BAAB9D` | 중간 톤 |
| `#A29282` | 짙은 토프 |
| `#7F7055` | 올리브브라운 |
| `#4F4D33` · `#343324` | 깊은 올리브 |
| `#0B0809` | 거의 검정 |

**케이스에 명시된 원칙** (원문에서)

- minimalism with intention — 의도가 있는 미니멀
- quiet materiality — 조용한 물성
- design that does not decorate, but defines — 장식하지 않고 정의하는 디자인
- 웰니스 시장의 클리셰를 피하고 건축적·정제된 언어를 택함

**규칙으로 정리하면**

- 채도를 죽인다. 원색이 하나도 없다.
- 따뜻한 뉴트럴(모래·토프·올리브)만으로 전체를 구성한다.
- 색으로 시선을 끌지 않고, 여백과 물성으로 만든다.

## 세 곳의 공통점

서로 성격이 다른데도 일치하는 것들 — 이게 진짜 규칙이다.

1. **폰트는 한 벌.** 세 곳 다 사실상 단일 서체.
2. **텍스트는 검정.** 셋 다 `#000` 계열이 압도적 1위.
3. **강조색은 하나.** MLB 검정 / GOLDY 빨강 / riosense 올리브. 두 개 이상 쓰지 않는다.
4. **그라데이션이 없다.** 배경은 전부 단색.
5. **본문이 작다.** 12~16px. 크게 키우지 않는다.
6. **밝다.** 셋 다 흰색·밝은 회색 기반이다.

## 서로 갈리는 것 — 선택해야 할 축

| 축 | MLB | GOLDY |
|---|---|---|
| 모서리 | 18~24px 크게 | 0px 직각 |
| 자간 | normal | 0.65~3.12px |
| 본문 | 16px | 12px |
| 배경 | `#f8f8f8` | `#ffffff` |

둘을 섞으면 어중간해진다. 한쪽을 골라야 한다.

## 테리·아큐 사이트에 적용할 때

현재 사이트는 **다크 무드 + 글래스모피즘**으로 만들어져 있는데, 레퍼런스 셋은 **전부 밝은 사이트**다. 이건 정면으로 충돌하므로 방향을 정해야 한다.

가져올 수 있는 것 (다크를 유지하더라도 유효):

- Pretendard 단일 서체 — 이미 적용됨
- 굵기 400/700 이분법으로 정리
- 자간 `normal` (한글 본문)
- 텍스트 3단 위계
- 강조색 1개로 축소 — 현재 테리 코랄 + 아큐 민트 2개는 레퍼런스 규칙 위반
- 그라데이션 제거 — 현재 비네트가 그라데이션을 쓰고 있음
- GOLDY의 `PRE ORDER` 히어로 타이포 패턴
- 모서리는 MLB식 18~24px 또는 GOLDY식 0px 중 택일 (현재 18px = MLB 쪽)

## 4. 29CM (29cm.co.kr) — 2026-08-23 추가 조사

"AI가 만든 티"를 없애려고 추가로 실측한 곳. MLB와 같은 커머스인데 값이 크게 다르다.

| 항목 | 실측값 |
|---|---|
| 폰트 | **Pretendard Variable 단일** (3,519개 요소) |
| 본문 | **12px(212) · 10px(186) · 13px(155) · 11px(84)** |
| 굵기 | 700(349) · **500(323)** · 400(150) |
| 자간 | `normal` — 822곳 전부, 다른 값 없음 |
| 라운드 | **2px(205) · 4px(171) · 6px(62)** |
| 배경 | `rgba(93,93,93,0.08)` 반투명 회색(153) · `#f4f4f4` · `#f7f7f7` |

**MLB와 갈리는 지점**

| | MLB | 29CM |
|---|---|---|
| 본문 | 16px | **12~13px** |
| 라운드 | 18~24px | **2~6px** |
| 굵기 | 400/700 | 400/500/700 |

**여기서 얻은 규칙 — 생성형 티를 없애는 법**

AI가 만든 화면이 티 나는 이유는 대개 이 조합이다:
본문 16px + 라운드 16~24px + 대칭 카드 그리드 + 영문 대문자 eyebrow + 아이콘·제목·설명 3종 세트.

실제 한국 커머스는 반대로 간다:

- 본문을 **12~14px**로 작게 쓴다
- 라운드를 **2~6px**로 거의 안 굴린다
- 카드 대신 **헤어라인 구분선**과 여백으로 나눈다
- 테두리 대신 **반투명 회색 면**(`rgba(93,93,93,0.08)`)을 쓴다
- 자간은 손대지 않는다
- 대칭 그리드보다 **좌측 라벨 레일 + 우측 본문**의 비대칭 편집 구조를 쓴다
