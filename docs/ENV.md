# 환경변수

`.env` 는 **git 에 올라가지 않는다**(`.gitignore` 에서 `.env*` 를 통째로 막는다).
그래서 값의 목록은 여기에 적어 둔다. 배포할 때는 이 표를 보고 플랫폼 대시보드에 넣으면 된다.

키가 하나도 없어도 **화면·3D·게임·체험 예약은 전부 동작한다.** 안내 문자와 결제만 멈춘다.

## 부스 체험 예약

| 이름 | 설명 | 비우면 |
|---|---|---|
| `SOLAPI_API_KEY` | 문자 발송 대행사(Solapi) 키 | 문자 발송만 멈춤 |
| `SOLAPI_API_SECRET` | 〃 시크릿 | 〃 |
| `SMS_SENDER` | 사전 등록한 발신번호, 숫자만 (예: `01012345678`) | 〃 |
| `KAKAO_PFID` | 카카오 채널 발신 프로필 id — 알림톡을 쓸 때만 | 문자(SMS)로 나감 |
| `KAKAO_TEMPLATE_BOOKED` | 접수 안내 템플릿 id | 〃 |
| `KAKAO_TEMPLATE_CALLUP` | 호출 템플릿 id | 〃 |
| `BOOTH_ADMIN_PASSWORD` | 운영 화면 비밀번호 | 개발 `3618` / **배포에서는 운영 화면이 잠긴다** |
| `BOOTH_DATA_DIR` | 예약 기록을 둘 폴더 | `server/data/` |

**배포에서는 이 값이 없으면 운영 화면이 아예 열리지 않는다.** `3618` 은 개발 편의용 기본값일 뿐이고,
이 저장소를 본 사람은 누구나 아는 값이라 배포에서는 기본값으로 넘어가지 않게 막아 두었다.
방문자 예약은 이 값이 없어도 정상 동작한다 — 잠기는 것은 명단 쪽뿐이다.

**`BOOTH_DATA_DIR` 은 배포에서 필수에 가깝다.** 호스팅 플랫폼의 파일 시스템은 대개
휘발성이라, 붙여 둔 디스크(예: `/data`)를 가리키지 않으면 서버가 다시 뜰 때 그날의 줄이
통째로 사라진다.

## 결제 (지금은 화면 어디에서도 링크하지 않는다)

| 이름 | 설명 |
|---|---|
| `TOSS_SECRET_KEY` | 서버에서만 쓴다. 절대 화면 코드로 넘기지 말 것 |
| `VITE_TOSS_CLIENT_KEY` | 토스 클라이언트 키(원래 공개용) |

> `VITE_` 로 시작하는 값은 빌드할 때 **화면 코드 안에 그대로 박힌다.** 브라우저에서 누구나
> 꺼내 볼 수 있다는 뜻이다. 비밀로 해야 하는 값에는 절대 `VITE_` 를 붙이지 말 것.

## 서버

| 이름 | 설명 | 비우면 |
|---|---|---|
| `API_PORT` | 서버 포트 | 8787 (배포에서는 플랫폼이 주는 `PORT`) |
| `API_HOST` | 바인딩 주소 | 개발 `127.0.0.1` / 배포 `0.0.0.0` |

- 배포 플랫폼에서는 포트를 **건드리지 않는다.** 플랫폼이 `PORT` 로 알려 주고 서버가 그것을 받는다.
- 같은 와이파이의 휴대폰이 개발 서버에 붙어야 하면 `API_HOST=0.0.0.0`.

## 견본이 필요하면

`.env` 를 새로 만들 때는 위 표의 이름만 왼쪽에 적고 값을 비워 두면 된다.

```
SOLAPI_API_KEY=
SOLAPI_API_SECRET=
SMS_SENDER=
BOOTH_ADMIN_PASSWORD=
BOOTH_DATA_DIR=
TOSS_SECRET_KEY=
VITE_TOSS_CLIENT_KEY=
```
